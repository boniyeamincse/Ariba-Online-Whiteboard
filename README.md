## 🚀 Features

Experience a seamless drawing experience with our robust toolset:

- **∞ Infinite Canvas**: Pan and zoom without limits or loss of quality.
- **🎨 Advanced Tools**:
    - **Brush**: Smooth freehand drawing with customizable stroke width and color.
    - **Eraser**: Precision removal of elements.
    - **Highlighter**: Semi-transparent emphasis for annotating.
    - **Shapes**: Draw perfect Rectangles, Circles, and Lines instantly.
    - **Text**: On-canvas WYSIWYG text editing.
    - **Sticky Notes**: Create yellow sticky notes for brainstorming sessions.
- **💾 Project Persistence**:
    - **Save Project**: Export your entire workspace state as a `.json` file.
    - **Open Project**: Restore your work instantly from a saved file.
    - **Export Image**: Save your masterpiece as a high-quality `.jpg` image.
- **⚡ Helpers**:
    - **Grid System**: Infinite background grid for perfect alignment.
    - **Zoom Controls**: Easy-to-use UI interaction for precise zoom management.

## 🛠️ Tech Stack

This project is built with a focus on performance and simplicity:

- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Graphics**: HTML5 Canvas API
- **Icons**: FontAwesome (CDN)
- **Fonts**: Google Fonts (Roboto)

## 🏁 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites
- A modern web browser (Chrome, Firefox, Edge, Safari).
- Git (optional, for cloning).

### Installation

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/boniyeamincse/Ariba-Online-Whiteboard.git
    ```
2.  **Navigate to the project directory**:
    ```bash
    cd Ariba-Online-Whiteboard
    ```
3.  **Open the application**:
    - Simply double-click `index.html` to open it in your default browser.
    - OR serve it with a local server (e.g., Live Server in VS Code, Python):
    ```bash
    # using python
    python3 -m http.server
    ```

## 🎮 Usage

1.  **Select a Tool**: Click on any icon in the bottom toolbar (Brush, Shape, Text, etc.).
2.  **Draw/Edit**: Click and drag on the canvas to draw.
3.  **Pan/Zoom**:
    - **Pan**: Hold `Spacebar` + Drag (or Middle Mouse Button).
    - **Zoom**: content using `Ctrl` + `Scroll` or the zoom buttons on the left.
4.  **Save/Load**: Use the top menu bar to simple save your progress or export an image.
